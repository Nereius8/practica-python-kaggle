# Práctica: Python, Git/GitHub y Análisis en Kaggle

Trabajo práctico de desarrollo de aplicaciones y gestión de entornos técnicos.

## 📂 Estructura del Repositorio
- `ejercicios.py`: Código fuente con la resolución de los problemas en Python (filtrado, frecuencia y conjuntos).
- `texto.txt`: Archivo de texto auxiliar utilizado para las pruebas de lectura y procesamiento.
- `img/`: Carpeta que almacena las evidencias visuales y capturas de pantalla de la práctica.

* **Usuario de GitHub:** `Nereius8`[cite: 2]
