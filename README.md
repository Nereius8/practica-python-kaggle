# Práctica: Python, Git/GitHub y Análisis en Kaggle

Trabajo práctico de desarrollo de aplicaciones y gestión de entornos técnicos.

## 📂 Estructura del Repositorio
- `ejercicios.py`: Código fuente con la resolución de los problemas en Python (filtrado, frecuencia y conjuntos).
- `texto.txt`: Archivo de texto auxiliar utilizado para las pruebas de lectura y procesamiento.
- `img/`: Carpeta que almacena las evidencias visuales y capturas de pantalla de la práctica.

---

## 🚀 Apartados del Proyecto

### Apartado 1: Control de Versiones con Git y GitHub
Creación del repositorio remoto `practica-python-kaggle` y gestión de ramas e incidencias desde la terminal de macOS.

### Apartado 2: Programación en Python
Implementación de scripts eficientes para el procesamiento de colecciones de datos, diccionarios de frecuencia y operaciones con conjuntos en Python 3.

### Apartado 3: Exploración en Kaggle
Consulta de competiciones activas y obtención de datasets de Machine Learning.
* **Competición seleccionada:** Titanic - Machine Learning from Disaster.
